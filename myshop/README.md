# 📁 Веб-приложение на встроенном HTTP-сервере Python

Простое веб-приложение, реализованное на чистом Python без использования фреймворков. Сервер обрабатывает GET и POST запросы, отдаёт HTML-страницы, стилизованные с помощью Bootstrap, и выводит данные форм в консоль.

# 🚀 Функционал

Главная страница (/) — приветственный блок с ссылкой на контакты  
Страница контактов (/contacts) — форма обратной связи с полями: 

Имя  
Email  
Сообщение  
Обработка POST-запросов — данные из формы выводятся в консоль сервера  
Обработка ошибок: 

404 Not Found — для несуществующих страниц  
500 Internal Server Error — при внутренних ошибках    
Адаптивная вёрстка с использованием Bootstrap 5 (подключение через CDN)
